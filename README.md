A deterministic Node program that writes one honest status-page line (151 characters, no trailing newline) to `/output/entry.txt` for a total outage: every server is down, the AI agent posting it cannot reach any system to check logs or verify the cause or scope, and it does not know when service returns.

## Run it

```sh
node main.ts
```
